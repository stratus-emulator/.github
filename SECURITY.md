# Security policy

stratus is an emulator for development and tests. It does not check signatures or credentials and has no login,
by design: never expose it to a network you do not trust.

## Reporting a vulnerability

Report it privately through GitHub's **private vulnerability reporting**: open the repository's **Security** tab
and choose **Report a vulnerability**. Please do not open a public issue.

Include what you found, how to reproduce it and the version (image tag or commit). We aim to answer within a week,
and to publish a fix and an advisory once it is ready, crediting you unless you ask us not to.

## Supported versions

Fixes go into the latest release only.
